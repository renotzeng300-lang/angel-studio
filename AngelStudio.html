API 金鑰設定

這個工作室透過 fal.ai 生圖，按張計費，沒有每日上限。金鑰只存在這台電腦的瀏覽器裡，不會傳到 fal 以外的地方。

  1. 到 fal.ai 註冊並登入
  2. 在 Billing 儲值（先儲 5–10 美元就夠試很久）
  3. 到 Dashboard → API Keys 建立一組金鑰，複製貼到下面
fal API Key
花費紀錄

花費是依官方牌價估算的，實際金額以 fal 後台帳單為準。
